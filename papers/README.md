# Paper PDFs

Policy:
1. Prefer **final published OA** (USENIX, SpringerOpen, MDPI, IEEE OA) over arXiv.
2. Author-posted finals OK (`version_kind: author_copy`).
3. If only preprint exists, store and mark `preprint`; **replace** when final OA appears (do not keep both as current).
4. Paywalled HTML is not stored. Vendor firmware blobs are **not** mirrored — see `data/datasets.jsonl` `OFFICIAL_LINK`.

See `PDF_MANIFEST.jsonl` and `../catalogs/surveys.md`.
